# telegram-vape-lead-bot

Telegram-юзербот на [Telethon](https://github.com/LonamiWebs/Telethon), который:

- вступает в список групп из `groups.txt` (только в новые — уже закешированные группы повторно не резолвятся и не подписываются, см. `joined_groups.json`);
- слушает сообщения в этих группах и ищет запросы вида «куплю/ищу …», отфильтровывая по бан-словам и длине сообщения;
- пересылает найденные заявки списку получателей в ЛС;
- раз в сутки шлёт владельцу сводный отчёт по статистике;
- управляется командами в ЛС от владельца (`/help`, `/addgroup`, `/addword`, `/addadmin` и т.д.).

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

1. Получите `api_id` и `api_hash` на <https://my.telegram.org>.
2. Скопируйте `secrets.example.json` в `secrets.json` и впишите свои `api_id`, `api_hash` и `owner_id` (ваш Telegram-username — единственный, кто может слать боту команды управления).
3. Заполните `groups.txt` — по одной ссылке/юзернейму группы на строку.
4. Запустите:

   ```bash
   python veip.py
   ```

   При первом запуске появится запрос авторизации Telethon (номер телефона + код), после чего создастся файл сессии `session.session` — он приватный, в репозиторий не попадает.

`config.json` (получатели уведомлений и бан-слова) и `joined_groups.json` (кеш уже посещённых групп) создаются автоматически при первом запуске и в репозиторий тоже не попадают — редактируются командами бота в ЛС.

## Файлы

- `veip.py` — основной юзербот.
- `get_ids.py` — вспомогательный скрипт для проверки последних сообщений в «Избранном» той же сессии.
- `veip_autostart.bat` — автозапуск на Windows.

## Безопасность

`secrets.json` и `session.session` дают полный доступ к Telegram-аккаунту — никогда не публикуйте и не коммитьте их (они уже в `.gitignore`).
